# Сотрудники

Android-приложение для хранения списка сотрудников. У каждого сотрудника есть фото, ФИО и возраст. Данные хранятся в SQLite.

## Что нужно

- Android Studio (последняя версия)
- Эмулятор или телефон на Android 7.0 и выше

## Как запустить

1. Склонировать репозиторий:
   ```
   git clone https://github.com/mkq4/android-employees.git
   ```
2. Открыть Android Studio → **File → Open** → выбрать папку проекта.
3. Подождать, пока закончится Gradle Sync.
4. Выбрать эмулятор или подключённый телефон и нажать **Run** ▶.

## Как пользоваться

- **Добавить сотрудника** — открывает экран добавления. Нажать на картинку, чтобы выбрать фото, ввести ФИО и возраст, нажать **Сохранить**.
- **Удалить сотрудника** — долгое нажатие на строку в списке.
